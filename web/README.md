# Wrapper pages

As deployed on dresa.org.au. To reuse: replace the two chat iframe/button URLs with your own Dify app links, swap the ARDC logo and branding, and keep the patterns that matter: the source-attribution footer, the latency expectation note, the open-in-full-window strip (embedded chats lose history in privacy-strict browsers), and the scroll-pin script (the chat autofocus otherwise scrolls the page header away).
